## 📌 Executive Summary & Academic Regulations

The laboratory component of **MIAE 215** introduces mechanical, industrial, and aerospace engineers to physical computing, digital sensor interfaces, real-time actuation, and embedded C++ programming on the **Atmel ATmega328P (Arduino Uno)** platform.

## ⚖️ Key Course Policies & Guidelines

1. **Individual Work Required**: Each student must own or have personal access to an Arduino kit. Students work individually on labs and the term project. No group submissions or code sharing is permitted.
2. **Attendance Policy**: Attendance in the physical lab rooms is **completely optional**. Full step-by-step PDF manuals, video podcasts, and official solution code sets are posted online. If you can complete the labs independently at home, you do not need to attend in person. In-person sessions serve as open support hours with Teaching Assistants (TAs).
3. **Lab Section Flexibility**: You may attend another lab section if you require help, provided physical seating and workstations are available.
4. **Graded Deliverables**:
   * **Labs 1, 2, and 3 are NOT handed in**. They are self-directed practice modules with official solutions provided.
   * **Only the Arduino Term Project is submitted for a grade** via Moodle.
5. **Direct Exam Impact (10%)**: Approximately **10% of the MIAE 215 Final Examination** consists of embedded C++ programming and circuit analysis questions drawn directly from the Arduino labs and project concepts!
