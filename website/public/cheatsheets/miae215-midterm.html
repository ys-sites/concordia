Precedence & Traps Logic
  • Precedence: () [] x++ x-- → ++x --x ! (type) sizeof (R-to-L) → * / % → + - → << >> → < <= > >= → == != → && → || → ?: → = += -= *=.
  • Prefix vs Postfix: y=++x (increments x first, assigns new x); y=x++ (assigns original x, then increments).
  • Chained Relational Trap: 1 < x < 5 → (1 < x) < 5 → (0 or 1) < 5 is ALWAYS TRUE! Must write: (1 < x && x < 5).
  • Assignment in if: if(x = 5) assigns 5 and is always true! Must write if(x == 5).
  • Short-Circuit: In A && B, if A is false, B is skipped. Protects bounds: if(i < n && A[i] > 0)!
Loops & Branching Flow
  • Dangling else: Binds to closest unmatched if! Always use explicit braces { }.
  • Switch: Must be integral (int/char/bool). No double! Each case requires break; or falls through.
  • Loop Trips: for(i=0;i<n;i++) (n trips, final i=n). for(i=0;i<=n;i++) (n+1 trips, final i=n+1).
  • Semicolon Trap: for(i=0;i<5;i++); { cout<<i; } loops empty 5 times, then prints 5 once!
  • Jump: break exits innermost loop/switch; continue jumps to update step. do{...}while(c); runs ≥ 1 time!

Arrays & C-Strings Memory
  • Partial Init: int A[5]={10,20}; → A[0]=10, A[1]=20, A[2]=A[3]=A[4]=0 (guaranteed zero, NOT garbage!).
  • Elements: int n = sizeof(A) / sizeof(A[0]);
  • 2D Matrix M[R][C]: Rows 0..R-1, cols 0..C-1. Passing to function requires col size: void f(double M[][4], int r).
  • C-String: char s[20]; MUST end with '\0'. strlen(s) excludes '\0'. Array size ≥ len+1.
  • Input: cin >> s; stops at space. cin.getline(s, 20); reads line including spaces.
Functions & File I/O Streams
  • Pass-by-Value: void f(int x) makes local copy; caller unchanged.
  • Pass-by-Reference: void f(int &x) receives alias; modifies caller! Swap: void swap(double &a, double &b){ double t=a; a=b; b=t; }
  • Arrays: Decay to pointer: void f(double A[], int n). Modifies caller array directly! Always pass n.
  • File Streams (<fstream>):
    • In: ifstream fin("in.txt"); if(!fin) return 1;
    • Loop: while(fin >> val && n < MAX) A[n++] = val; fin.close();
    • Out: ofstream fout("out.txt"); fout << fixed << setprecision(3) << ans; fout.close();
