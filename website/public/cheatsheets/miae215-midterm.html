#1 Trap — Truncating Division: 7/2 = 3, 1/2 = 0, 1/(i+1) = 0 for i ≥ 1. Cast before: (double)a / b = 3.5. Note: (double)(a / b) = 3.0 (too late!).
Modulo % Rules: Integers only. Result sign strictly follows left operand: -7 % 3 = -1; 7 % -3 = 1; -7 % -3 = -1.
Precedence & Evaluation Order Logic / Short-Circuit
  • Strict Precedence: () [] x++ x-- → ++x --x ! (type) sizeof (R-to-L) → * / % → + - → << >> → < <= > >= → == != → && → || → ?: → = += -= *= (R-to-L).
  • Prefix vs Postfix: y = ++x; (increments x first, assigns new x). y = x++; (assigns original x, then increments x).
  • Chained Relational Trap: 1 < x < 5 parses as (1 < x) < 5. Since (0 or 1) < 5 is always 1, it is ALWAYS TRUE! Must write: (1 < x && x < 5).
  • Assignment in if: if(x = 5) assigns 5 to x and evaluates true! Always use equality test: if(x == 5).
  • Short-Circuit Protection: In A && B, if A is false, B is skipped. Safely protects array access: if(i < n && A[i] > 0)!
Control Flow, Loops & Semicolons Branches / Loop Trips
  • Dangling else: Binds to closest unmatched if regardless of indentation! Use explicit braces { }.
  • Switch Constraints: Expression must be integral (int, char, bool). Cannot switch on double/float! Each case requires break; or execution cascades through next cases!
  • Loop Iteration Trips:
    • for(i=0; i<n; i++) → runs exactly n times; final i = n.
    • for(i=0; i<=n; i++) → runs n + 1 times; final i = n + 1.
    • do { ... } while(cond); → guaranteed ≥ 1 run! Semicolon mandatory!
  • Semicolon Trap: for(i=0; i<5; i++); { cout<<i; } → empty body loops 5 times; then prints 5 once!
  • Jump Keywords: break exits innermost loop/switch; continue skips rest of body to next update step.

The Signature Garbage (G) Rule: For array A[4], valid indices are 0..3. When for(i=0; i<4; i++) terminates, i == 4! Printing cout << A[i]; accesses out-of-bounds memory → Write "Garbage" or "G" for full marks!
Arrays (1D & 2D) & C-Strings Memory Layout
  • Partial Initialization: int A[5] = {10, 20}; → A[0]=10, A[1]=20, and A[2]=A[3]=A[4]=0 (guaranteed zeroed, never garbage!).
  • Total Element Count: int n = sizeof(A) / sizeof(A[0]);
  • 2D Matrix Row-Major: M[R][C] has row i ∈ [0, R-1] and col j ∈ [0, C-1]. Cell address: *(M[0] + i*C + j). When passing to functions, column size MUST be constant: void f(double M[][4], int r).
  • C-String Null Terminator: char s[20]; MUST end with '\0' (ASCII 0). Size must be ≥ length + 1! strlen(s) counts chars excluding '\0'.
  • Stream Reading: cin >> s; stops at whitespace. cin.getline(s, 20); reads entire line including spaces up to 19 characters.
Functions, References & File I/O Modular Design
  • Pass-by-Value: void f(int x) → makes local copy; changes inside do NOT modify the caller's variable.
  • Pass-by-Reference: void f(int &x) → receives memory alias; changes directly modify caller! Classic swap: void swap(double &a, double &b){ double t=a; a=b; b=t; }
  • Arrays to Functions: Always decay to pointers: void f(double A[], int n). Modifies caller array directly! Array size cannot be known via sizeof inside function; always pass n.
  • File Streams (<fstream>):
    • Reading: ifstream fin("data.txt"); if(!fin) return 1;
    • Reading loop: while(fin >> val && n < MAX) A[n++] = val; fin.close();
    • Writing: ofstream fout("out.txt"); fout << fixed << setprecision(3) << ans; fout.close();
