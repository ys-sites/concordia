  • Overflow: int past its max wraps (undefined behavior). 100000 × 100000 needs 100000LL * 100000 — the product is computed in int before any assignment.
  • sizeof(double) = 8, sizeof(int) = 4.

Integer Division — the #1 Trap

  • 7 / 2 = 3 (int ÷ int truncates toward zero); -7 / 2 = -3
  • To get 3.5: cast before dividing — (double)a / b, a / 2.0, static_cast<double>(a) / b
  • (double)(a / b) = 3.0 — the cast comes too late, division already truncated.
  • % = remainder; sign follows the left operand: -7 % 2 = -1, 7 % -2 = 1
  • n % 10 = last digit · n % 2 == 0 = even test · a % b needs ints only
  • Formulas: write 5.0 / 9.0, never 5 / 9 (= 0!).

Operator Precedence (high → low)

  • ( ) → unary ! - ++ -- → * / % → + - → < <= > >= → == != → && → || → =
  • a++ uses THEN increments; ++a increments first. int b = a++; → b gets old a.
  • && and || short-circuit: right side skipped if the answer is already decided.
  • = assigns, == compares. if (x = 5) compiles and is always true!

if / if-else Ladders

if      (score >= 90) grade = 'A';
else if (score >= 80) grade = 'B';
else if (score >= 70) grade = 'C';
else                   grade = 'F';
  • Test boundaries high → low; the first true branch wins, the rest are skipped.
  • Plain ifs are NOT exclusive — several can all run.
  • else binds to the nearest if.
  • Never compare doubles with == (round-off!): use fabs(a - b) < 1e-9.
  • ; after if (...) = empty body — the next line always runs.

Loops

for (init; cond; update) { ... }
while (cond) { ... update! ... }
do { ... } while (cond);   // runs ≥ 1 time
  • Trip counts: i=0; i<10; i++ = 10 · i<=10 = 11 · i=1; i<10 = 9 · step 2 halves it.
  • break exits the loop; continue jumps to the next iteration.
  • Nested loops: outer = rows, inner = columns; put "\n" after the inner loop.
  • Infinite loop: while-loop with no update, or a condition that never turns false.

Accumulator Patterns (write-a-program gold)

Sum:      int s = 0;  s += x;
Product:  int f = 1;  f *= i;        // factorial: init 1!
Count:    int c = 0;  if (ok) c++;
Max:      int m = first; if (x > m) m = x;
Average:  (double)s / n;             // cast!
  • Sum starts at 0, product starts at 1 — wrong seed = wrong answer.
  • Uninitialized accumulator = garbage. Always initialize.

cmath & I/O

  • #include <cmath>: sqrt(x), pow(x, y), fabs(x), sin/cos/tan (radians!).
  • abs(int) is in <cstdlib>; use fabs for doubles.
  • cout << x << "\n"; · read with cin >> x; · chain: cin >> a >> b;
  • Program skeleton: #include <iostream> + using namespace std; + int main() { ... return 0; }

Last-Minute Trap Checklist

  • ☐ Integer division — cast before dividing, and before averaging.
  • ☐ = vs == in every condition.
  • ☐ Stray ; after if / for headers.
  • ☐ Off-by-one: < vs <= on loop bounds; count the trips.
  • ☐ Accumulators initialized (0 for sum, 1 for product).
  • ☐ Ladder order high → low; boundary values use >=.
  • ☐ Tracing: write each variable's value per line — never trace in your head.
  • ☐ NOT on the exam: 2D arrays, flowcharts, Arduino/lab.
