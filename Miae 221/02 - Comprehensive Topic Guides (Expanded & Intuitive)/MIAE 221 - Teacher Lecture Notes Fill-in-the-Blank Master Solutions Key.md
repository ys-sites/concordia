## Quick Reference: Your Specific Question

> **Slide Prompt (Lecture 7, Slide 13 — Hume-Rothery Rule 1):**  
> *"For appreciable substitutional solubility to occur the following factors must hold:*  
> *• Atomic size factor: the difference in atomic radii between the two atoms must be $\le$ ........."*

### The Answer: **$\le \pm 15\%$** (or simply **$15\%$**)

* **Textbook Reference**: *Callister (10th Ed.)*, Section 4.3 (page 112):  
  $$\Delta R = \left|\frac{R_{\text{solute}} - R_{\text{solvent}}}{R_{\text{solvent}}}\right| \times 100\% \le 15\%$$
* **Physical Reason**: If the solute atom's radius differs by more than $15\%$, severe local lattice strain (compressive if oversized, tensile if undersized) destabilizes the host lattice, causing the system to separate into a distinct second phase rather than forming a substitutional solid solution.

## Pedagogical Summary & Midterm Advice

1. **Calculations**: Always memorize the $a \leftrightarrow R$ relations:
   * **BCC**: $a\sqrt{3} = 4R \implies a = \frac{4R}{\sqrt{3}}$
   * **FCC**: $a\sqrt{2} = 4R \implies a = 2\sqrt{2}R$
2. **Hume-Rothery Rules**: If an exam question asks whether an alloy forms a solid solution, test all 4 rules:
   * **Cu-Ni**: Radius difference $2.3\% < 15\%$, both FCC, $\Delta X = 0.1$, compatible valency $\implies$ **Complete isomorphous solid solution**.
   * **Cu-Zn**: Crystal structures differ (FCC vs HCP) $\implies$ **Limited solubility only** ($\le 35\text{ wt}\%$).
3. **Vacancy Activation Energy**: Plotting $\ln(N_v/N)$ versus $1/T$ yields a straight line with slope $= -Q_v/k_B$. Use $k_B = 8.617 \times 10^{-5}\text{ eV/K}$ when $Q_v$ is given in $\text{eV}$.
