## ⚡ Master Formula Reference Card

| Concept | Mathematical Equation | Key Notes & Units |
| :--- | :--- | :--- |
| **Net Potential Energy** | $E_N(r) = -\frac{A}{r} + \frac{B}{r^n}$ | $A$: attractive factor; $B$: repulsive factor ($n \approx 8-12$) |
| **Net Interatomic Force** | $F_N(r) = -\frac{dE_N}{dr} = -\frac{A}{r^2} + \frac{nB}{r^{n+1}}$ | At $r_0$, $F_N(r_0) = 0 \iff F_A = -F_R$ |
| **Equilibrium Spacing** | $r_0 = \left( \frac{nB}{A} \right)^{\frac{1}{n-1}}$ | Location of potential energy minimum |
| **Bonding Energy** | $E_0 = -\frac{A}{r_0}\left(1 - \frac{1}{n}\right) = -\frac{A(n-1)}{n r_0}$ | Magnitude equals work to break bond; $|E_0| \propto T_m$ |
| **Coulombic Attraction** | $F_A = \frac{\|z_1 z_2\| e^2}{4\pi \varepsilon_0 r^2}$ | $e = 1.602 \times 10^{-19}\text{ C}, \varepsilon_0 = 8.854 \times 10^{-12}\text{ F/m}$ |
| **Percent Ionic Character**| $\% \text{IC} = \left[1 - \exp\left(-0.25(X_A - X_B)^2\right)\right] \times 100\%$ | $X_A, X_B$: Pauling electronegativities |
| **Theoretical Density** | $\rho = \frac{n \cdot A}{V_c \cdot N_A}$ | $n$ = atoms/cell ($BCC=2, FCC=4, HCP=6$), $V_c$ = cell volume |
| **FCC Unit Cell & APF** | $a = 2\sqrt{2}R, \quad \text{APF} = \frac{\pi\sqrt{2}}{6} \approx 0.74$ | Close-packed planes: $\{111\}$, directions: $\langle 110 \rangle$ |
| **BCC Unit Cell & APF** | $a = \frac{4R}{\sqrt{3}}, \quad \text{APF} = \frac{\pi\sqrt{3}}{8} \approx 0.68$ | Close-packed directions: $\langle 111 \rangle$ |
| **Miller Indices (Planes)**| $(hkl) = \left( \frac{1}{x_{int}}, \frac{1}{y_{int}}, \frac{1}{z_{int}} \right) \times \text{LCD}$ | Enclosed in parentheses; overbar for negative intercepts |
