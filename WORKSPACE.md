# Workspace guide

Use this directory as the main Concordia workspace. The current website is in
`website/`, and the course materials are in the course folders at the root.

`Local Semester Archive/` is ignored by Git and contains recovery material from
the attempted consolidation, including copies of the older checkout's untracked
course PDFs and its unpushed commit patch. The move was blocked by Windows
permissions, so the original `../Semester 1/` folder remains in place and is
still needed for its other private course materials, older file versions,
resource library, and Git history. Do not delete either copy until the complete
migration has been verified.

The visual-learning research blueprint is `THE_NEXT_STEP.md`.
