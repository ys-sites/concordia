
1) The table based approach for output problems was mainly 
intended to show you how to systematically solve for outputs 
and for more difficult output questions.
The table based approach is not required to solve the output 
questions on the midterm. You can use a simplified version or 
just make some notes on how the key variable change instead.

2) You won't submit a table for the output questions on the 
midterm. There won't be any part marks for the table.

3) The difficulty level of the programming questions will
be similar to the old quizzes from the review material.
Some of the most difficult assignment questions and lecture 
examples would be considered too difficult or time consuming
for the midterm, unless you have seen a similar problem
before in the lectures or assignments.

4) To study for the programming question I recommend solving
the old quizzes, review problems, exercise problems, 
assignment problems, and lecture examples.

5) To study for the output problems I recommend solving
the output questions from the review problems, exercise problems,
and assignments.

6) If you need more practice with output problems try making 
small changes to the existing output questions and solving 
them again -- you can get the solutions by compiling and 
executing the output question.

7) There won't be any 2D array questions on the midterm exam.
However there will 1D array problems (both output and programming).
